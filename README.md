# Система анализа тональности отзывов маркетплейса

Полностью готовая программная система (веб-приложение) на базе **Streamlit** для загрузки, интеллектуального аспектного анализа, визуализации и экспорта отзывов. Приложение разработано в рамках Выпускной квалификационной работы (ВКР).

Система анализирует тексты отзывов по четырем ключевым аспектам и выявляет их тональность, формируя наглядные аналитические дашборды.

---

## 🌟 Возможности системы

- **Поддержка форматов:** Загрузка таблиц с отзывами в форматах `CSV` и `XLSX`.
- **Гибкость данных:** Автоматическое определение структуры файла и возможность ручного выбора текстового столбца.
- **Интеллектуальный анализ:** Выявление тональности (позитивная, негативная, нейтральная) по **четырём** ключевым аспектам:
  - 📦 Качество товара
  - 📝 Соответствие описанию
  - 🎁 Упаковка
  - 🚚 Доставка
- **Визуализация (Дашборды):** Построение наглядных интерактивных графиков (Plotly), показывающих долю негатива и распределение тональности.
- **Экспорт данных:** Формирование итоговых отчетов в широком формате (с отдельными колонками под каждый аспект) в CSV и XLSX.
- **Парсинг Wildberries:** Встроенный CLI-скрипт для публичного парсинга отзывов WB по артикулу товара.

## 🛠 Установка и запуск

1. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python -m venv venv
   
   # Для Windows:
   venv\Scripts\activate
   
   # Для Linux / macOS:
   source venv/bin/activate
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустите систему:**
   ```bash
   streamlit run app.py
   ```
   После запуска приложение будет доступно в браузере по адресу: `http://localhost:8501`

## ⚙️ Настройка сервиса аналитики

Система использует внешние сервисы для анализа текстов. Для локального запуска необходимо создать файл `.env` в корне проекта и указать данные для авторизации.

### Вариант 1: Использование GigaChat
```env
LLM_PROVIDER=gigachat
GIGACHAT_CREDENTIALS=ваш_authorization_key
GIGACHAT_MODEL=GigaChat
GIGACHAT_BASE_URL=https://gigachat.devices.sberbank.ru/api/v1
# Для локальной разработки без строгой проверки сертификатов Минцифры:
GIGACHAT_VERIFY_SSL=false
```

### Вариант 2: Использование стандартного провайдера
```env
LLM_API_KEY=ваш_ключ_доступа
LLM_MODEL=gpt-4o-mini
```

> **Примечание:** Все ключи доступа используются строго на сервере (backend), не отображаются в интерфейсе пользователя и не сохраняются в экспортируемых отчетах. Интерфейс полностью нейтрален.

## 📊 Формат входного файла

Приложение ожидает таблицу (`CSV` или `XLSX`) со следующими полями:

| Поле | Статус | Описание |
|---|---|---|
| `review_text` | **обязательное** | Текст отзыва (название столбца можно выбрать в интерфейсе) |
| `review_id` | опциональное | Уникальный идентификатор отзыва |
| `product_name` | опциональное | Название товара |
| `rating` | опциональное | Числовая оценка (от 1 до 5) |
| `date` | опциональное | Дата публикации отзыва |

## 📥 Вспомогательный парсер Wildberries

Для удобства сбора тестовых данных в проекте предусмотрен консольный скрипт парсинга публичных отзывов Wildberries по артикулу (nmId).

Пример запуска (сбор до 50 отзывов):
```bash
python scripts/parse_wb_reviews.py 5870243 --limit 50
```
Скрипт сохранит собранные данные в папку `data/` в формате `wb_reviews_<nmId>.csv`. Полученный файл можно сразу загрузить в веб-приложение.

## 🧪 Тестирование

Система покрыта юнит-тестами. Для их запуска используйте команду:
```bash
pytest
```
Тесты проверяют загрузку данных, корректность агрегаций, очистку текста и мокируют внешние сетевые запросы, что позволяет проверять логику системы без расхода реальных токенов.
