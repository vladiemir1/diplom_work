# Система анализа тональности отзывов маркетплейса

Streamlit-приложение для загрузки, парсинга, аспектного анализа, визуализации и экспорта отзывов маркетплейса. MVP использует внешний NLP-модуль через OpenAI API и оставляет архитектурную возможность заменить его на локальную модель.

## Возможности

- загрузка CSV/XLSX;
- выбор текстового столбца;
- публичный парсинг отзывов Wildberries по ссылке на товар;
- сохранение WB-отзывов в `data/wb_reviews_<nmId>.csv`;
- предобработка текста;
- аспектный анализ с несколькими аспектами на один отзыв;
- русскоязычный интерфейс;
- графики Plotly;
- экспорт CSV и XLSX;
- unit-тесты.

## Установка

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

## Настройка LLM API

Создайте файл `.env` в корне проекта:

```env
LLM_API_KEY=ваш_ключ
LLM_MODEL=gpt-4o-mini
LLM_BASE_URL=
```

`LLM_MODEL` и `LLM_BASE_URL` необязательны. Если `LLM_BASE_URL` пустой, используется обычный OpenAI API. Для OpenAI также поддерживаются старые имена переменных `OPENAI_API_KEY` и `OPENAI_MODEL`.

Ключ можно также ввести в интерфейсе приложения. Он не хранится в коде, не попадает в таблицы результатов и не экспортируется.

### OpenAI-compatible провайдеры

Приложение использует OpenAI-compatible клиент. Поэтому можно подключать провайдеров, которые поддерживают Chat Completions API:

```env
LLM_API_KEY=ключ_провайдера
LLM_MODEL=модель_провайдера
LLM_BASE_URL=https://provider.example.com/v1
```

Примеры таких сценариев: OpenRouter, DeepSeek, Groq, локальный gateway или локальный сервер с OpenAI-compatible API. Конкретное имя модели и base URL нужно брать из документации выбранного провайдера.

## Формат входного файла

Поддерживаются CSV и XLSX. Поля:

| Поле | Обязательность | Описание |
|---|---|---|
| `review_id` | необязательное | идентификатор отзыва |
| `product_name` | необязательное | название товара |
| `rating` | необязательное | числовая оценка |
| `review_text` | необязательное | текст отзыва |
| `date` | необязательное | дата отзыва |

Если `review_text` отсутствует, приложение предложит выбрать любой другой текстовый столбец.

## Вспомогательный парсер Wildberries

Парсер не встроен в основной интерфейс приложения, чтобы MVP соответствовал ТЗ ВКР. Он доступен отдельным CLI-скриптом и создаёт CSV, который затем можно загрузить в приложение как обычный файл.

Пример запуска:

```bash
python scripts/parse_wb_reviews.py "https://www.wildberries.ru/catalog/5870243/detail.aspx" --limit 100
```

Можно передать и сам артикул:

```text
python scripts/parse_wb_reviews.py 5870243 --limit 50
```

Скрипт извлечёт `nmId`, попробует получить публичные отзывы и сохранит CSV в папку `data/`:

```text
data/wb_reviews_<nmId>.csv
```

Важно: парсер работает без WB API-ключа продавца и зависит от публичных endpoint Wildberries. Если Wildberries ограничит доступ или изменит формат ответа, приложение покажет понятную ошибку.

## Аспекты анализа

- Качество товара
- Соответствие описанию
- Упаковка
- Доставка
- Общее впечатление

Тональность в коде хранится как `positive`, `negative`, `neutral`, а в интерфейсе показывается как `Положительная`, `Отрицательная`, `Нейтральная`.

## Структура проекта

```text

modules/wb_parser.py            публичный парсер WB

data/sample_reviews.csv         пример входных данных

tests/                          unit-тесты
```
