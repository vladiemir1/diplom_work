# Финальное техническое задание: MVP системы анализа отзывов маркетплейса

## 1. Назначение

Разработать локальное Streamlit-приложение на Python для загрузки, парсинга, анализа, визуализации и экспорта пользовательских отзывов маркетплейса.

MVP использует внешний NLP-модуль с возможностью последующей замены на локальную нейросетевую модель. Приложение должно быть пригодно для демонстрации в рамках ВКР и дальнейшего расширения.

## 2. Основные возможности

- Загрузка CSV/XLSX-файлов с отзывами.
- Выбор текстового столбца пользователем.
- Публичный сбор отзывов Wildberries по ссылке на товар без WB API-ключа.
- Сохранение спарсенных отзывов в `data/wb_reviews_<nmId>.csv`.
- Предварительная обработка текста.
- Аспектный анализ отзывов через LLM API.
- Поддержка OpenAI и OpenAI-compatible провайдеров через `LLM_API_KEY`, `LLM_MODEL`, `LLM_BASE_URL`.
- Учет рейтинга как дополнительного сигнала.
- Отображение результатов в таблицах и графиках.
- Экспорт результатов в CSV и XLSX.
- Хранение состояния в `st.session_state`.

## 3. Входные данные

Поддерживаемые поля:

| Поле | Обязательность | Описание |
|---|---|---|
| `review_id` | необязательное | идентификатор отзыва |
| `product_name` | необязательное | название товара |
| `rating` | необязательное | числовая оценка |
| `review_text` | необязательное при ручном выборе | текст отзыва |
| `date` | необязательное | дата отзыва |

Если `review_text` отсутствует, пользователь выбирает текстовый столбец вручную. Если `review_id` отсутствует, система создает его автоматически.

## 4. Аспекты и тональность

Аспекты анализа:

- `Качество товара`
- `Соответствие описанию`
- `Упаковка`
- `Доставка`
- `Общее впечатление`

Технические значения тональности:

- `positive`
- `negative`
- `neutral`

В интерфейсе отображаются русские подписи: `Положительная`, `Отрицательная`, `Нейтральная`.

## 6. Выходные таблицы

Предобработанная таблица:

```text
review_id, product_name, rating, date, review_text, processed_text, is_valid, error_message
```

Таблица результатов:

```text
review_id, product_name, rating, date, review_text, processed_text, aspect, sentiment, sentiment_label, confidence, explanation
```

Агрегированная таблица:

```text
aspect, mention_count, positive_count, negative_count, neutral_count, confidence_avg
```

## 7. Критерии готовности

- Приложение запускается командой `streamlit run app.py`.
- Загружаются CSV и XLSX.
- Работает выбор текстового столбца.
- Работает публичный парсер WB по ссылке, если endpoint Wildberries доступен.
- Спарсенные отзывы сохраняются в CSV.
- LLM API вызывается батчами.
- Результаты отображаются в таблицах и дашборде.
- Работает экспорт CSV/XLSX.
- Покрыты базовые unit-тесты.
