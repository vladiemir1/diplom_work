# Контекст ВКР

## Тема

Разработка системы анализа тональности пользовательских отзывов на маркетплейсе с использованием нейронных сетей.

## Смысл проекта

ВКР описывает систему, которая помогает продавцу или аналитику маркетплейса быстро обрабатывать пользовательские отзывы. Вместо ручного чтения система должна выделять проблемные зоны: качество товара, соответствие описанию, упаковку и доставку.

## Основные решения из документа

- Тип приложения: веб-приложение.
- Интерфейс: Streamlit.
- Основной язык: Python.
- Работа с таблицами: pandas.
- Визуализация: Plotly.
- Форматы входа и выхода: CSV/XLSX.
- Состояние приложения: `st.session_state`.
- Проектная модель: аспектный анализ тональности отзывов.
- Базовая нейросетевая идея: RuBERT как будущая локальная модель.

## Аспектная схема

- Качество товара: материал, внешний вид, работоспособность, надежность, брак.
- Соответствие описанию: фото, цвет, размер, заявленные характеристики.
- Упаковка: состояние коробки, защита товара, повреждения при перевозке.
- Доставка: сроки и процесс получения заказа.

В MVP также используется аспект `Общее впечатление`, чтобы корректно обрабатывать отзывы без конкретного аспекта.

## Требования из ВКР, важные для приложения

- Пользователь должен загружать отзывы через веб-интерфейс.
- Система должна поддерживать CSV и XLSX.
- Должна выполняться предварительная обработка текста.
- Один отзыв может содержать несколько аспектов.
- Для каждого аспекта определяется тональность.
- Результаты должны отображаться в таблицах и графиках.
- Нужен экспорт результатов.
- Логика интерфейса и аналитический модуль должны быть разделены.
